# Where to look things up

Give the owner the exact page for the concept in the current step, not a list. Prefer the official docs, then
Real Python for a friendlier walk-through. Every link here is a stable, well-known page; do not invent others.

## Learning to read docs and code
- Python tutorial (start here): https://docs.python.org/3/tutorial/index.html
- Built-in functions (`input`, `int`, `len`, `range`, `sorted`, `open`...): https://docs.python.org/3/library/functions.html
- Errors and exceptions (`try/except`, reading tracebacks): https://docs.python.org/3/tutorial/errors.html
- Python Tutor - watch code run line by line: https://pythontutor.com/
- W3Schools Python (quick examples): https://www.w3schools.com/python/
- Style guide PEP 8 (names, spacing, layout): https://peps.python.org/pep-0008/

## Imports, modules and packages
- Modules and packages (official): https://docs.python.org/3/tutorial/modules.html
- Real Python - how `import` works: https://realpython.com/python-import/
- Real Python - modules and packages: https://realpython.com/python-modules-packages/
- `if __name__ == "__main__":` explained: https://realpython.com/if-name-main-python/
- The standard library index (everything that needs no install): https://docs.python.org/3/library/index.html
